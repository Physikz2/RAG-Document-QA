# RAG Document QA System

A production-ready RAG (Retrieval-Augmented Generation) document question-answering system built with Python, LangChain, ChromaDB, and Gemini API.

## 🚀 Features

- 📄 Upload PDF or text documents
- 🔍 Automatic document chunking and embedding
- 🧠 RAG pipeline using Gemini LLM
- 💾 ChromaDB for vector storage
- 🌐 RESTful API with FastAPI
- 🎨 Clean web interface
- 🚀 Deployable to Render (free tier)

## 🛠️ Tech Stack

- **Backend**: FastAPI, Python
- **LLM**: Google Gemini (via LangChain)
- **Vector DB**: ChromaDB
- **Embeddings**: Gemini Embeddings
- **Frontend**: HTML, CSS, JavaScript
- **Deployment**: Render (backend), GitHub Pages (frontend)

## 📋 Prerequisites

- **Python 3.12**: This project is developed and tested with Python 3.12. Please ensure you have it installed.
- **Git** (optional, for cloning the repository)
- A **Gemini API key** from Google AI Studio
